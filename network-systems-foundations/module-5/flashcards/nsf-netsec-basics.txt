What is plaintext?	The unencrypted message, what the sender actually wants to transmit	MSCS::netfund::netsec::basics
What is ciphertext?	The output of the encryption algorithm, meaningless to an eavesdropper	MSCS::netfund::netsec::basics
What are the conventional names for the two communicating parties and the attacker?	Alice and Bob; attacker is Eve (also Mallory or Trudy)	MSCS::netfund::netsec::basics
In crypto notation, what does K_A(m) mean?	The ciphertext produced by encrypting message m with key K_A	MSCS::netfund::netsec::basics
What does m = K_B(K_A(m)) express?	Encrypting m with key K_A and then decrypting with key K_B recovers the original message	MSCS::netfund::netsec::basics
What is symmetric encryption?	Alice and Bob share one key, used for both encryption and decryption	MSCS::netfund::netsec::basics
What are the tradeoffs of symmetric encryption?	Fast and handles long messages, but you need a way to share the key securely	MSCS::netfund::netsec::basics
In the trivial XOR cipher example, what is the encryption and decryption algorithm?	XOR of each block with the shared key; XOR is its own inverse so both directions use the same operation	MSCS::netfund::netsec::basics
XOR example: plaintext byte 0x45 (ASCII E) with key 0xD7 (11010111) produces what ciphertext?	0x92	MSCS::netfund::netsec::basics
When did AES become a NIST standard and what key sizes does it support?	NIST standard in 2001; 128, 192, or 256 bit keys	MSCS::netfund::netsec::basics
What is asymmetric encryption?	One party generates a key pair; the private key is kept secret and the public key can be shared with anyone	MSCS::netfund::netsec::basics
In asymmetric encryption, which key encrypts and which decrypts when Alice sends to Bob?	Encrypt with Bob's public key, decrypt with Bob's private key	MSCS::netfund::netsec::basics
What are the tradeoffs of asymmetric encryption?	Slow and limited to shorter messages, but the key is simple to distribute since it does not matter who has the public key	MSCS::netfund::netsec::basics
What are the RSA key pairs and the encryption formula?	Public key (n,e), private key (n,d); ciphertext c = m^e mod n	MSCS::netfund::netsec::basics
What is the RSA decryption formula?	m = c^d mod n	MSCS::netfund::netsec::basics
In RSA, how is the message m represented?	As a bit pattern interpreted as an integer, which must be less than n	MSCS::netfund::netsec::basics
RSA example with p=5 and q=7: what are n and z?	n = p*q = 35; z = (p-1)(q-1) = 24	MSCS::netfund::netsec::basics
RSA example with n=35 and z=24: how are e=5 and d=29 chosen?	e must be relatively prime to z; d is chosen so that ed-1 is exactly divisible by z	MSCS::netfund::netsec::basics
RSA example: encrypting bit pattern 00001100 (m=12) with e=5 and n=35 gives what ciphertext?	12^5 = 24832, and 24832 mod 35 = 17	MSCS::netfund::netsec::basics
Why does RSA only work well on short messages?	m must be less than n and encryption requires exponentiating the whole message, which is computationally expensive	MSCS::netfund::netsec::basics
How are symmetric and asymmetric encryption combined in practice?	Asymmetric encryption is used to exchange a shared session key, then symmetric encryption carries the longer conversation	MSCS::netfund::netsec::basics
In the session key exchange, who picks the session key and how is it protected in transit?	Alice picks it and encrypts it with Bob's public key, so only Bob's private key can decrypt it	MSCS::netfund::netsec::basics
What is a hash function?	A function that calculates a fixed length digest from a variable length message	MSCS::netfund::netsec::basics
What is the desired security property of a hash function?	It is computationally infeasible to find another message that produces the same digest	MSCS::netfund::netsec::basics
What assumption does plain hashing rely on for integrity checking?	That the message digest itself is known and unmodified	MSCS::netfund::netsec::basics
Give the common real-world use of a plain hash for integrity.	Verifying software downloads by hashing the downloaded file and comparing to the published digest	MSCS::netfund::netsec::basics
What problem does HMAC solve that a plain hash does not?	It removes the assumption that the digest is known and unmodified, since an attacker in the middle could change both message and digest	MSCS::netfund::netsec::basics
What does HMAC require both parties to have?	A shared secret key	MSCS::netfund::netsec::basics
Write the HMAC construction shown in the lecture.	H(key || H(key || message))	MSCS::netfund::netsec::basics
What two things does a digital signature let the receiver verify?	That the message has not changed, and that it came from the claimed sender	MSCS::netfund::netsec::basics
In a digital signature, which key signs and which key verifies?	The sender's private key signs; the receiver uses the sender's public key to verify	MSCS::netfund::netsec::basics
How is a digital signature constructed?	Hash the message, then encrypt the hash with the sender's private key; the result is the signature	MSCS::netfund::netsec::basics
How does the receiver verify a digital signature?	Decrypt the signature with the sender's public key, hash the received message, and compare the two	MSCS::netfund::netsec::basics
What is the authentication problem in network security?	Ensuring you are communicating with who you expect, for example confirming a public key really belongs to Alice	MSCS::netfund::netsec::basics
What is a digital certificate?	Something that binds a public key to an identity, where the definition of identity depends on the context	MSCS::netfund::netsec::basics
What is the weakness of an unsigned digital certificate?	An attacker can modify it, swapping in their own public key while keeping the identity fields	MSCS::netfund::netsec::basics
What does a Certificate Authority do?	Verifies the identity of the certificate holder and signs the certificate with the CA's private key	MSCS::netfund::netsec::basics
How does anyone validate a CA-signed certificate, and how is the CA itself trusted?	Anyone can verify it with the CA's public key; the CA's public key must be trusted, typically pre-installed in the browser or OS	MSCS::netfund::netsec::basics

In the SA-1 exchange, who proposes and who decides?	The initiator says what it supports, the responder chooses	MSCS::netfund::netsec::ipsec
What does Diffie Hellman accomplish?	It lets two parties with no prior knowledge of each other jointly establish a shared secret key over an insecure channel	MSCS::netfund::netsec::ipsec
In Diffie Hellman, what does each side compute and send?	Both agree on prime p and base g; Alice picks secret x and sends h_A = g^x mod p, Bob picks secret y and sends h_B = g^y mod p	MSCS::netfund::netsec::ipsec
In Diffie Hellman, why do both sides arrive at the same key?	Alice computes (h_B)^x mod p and Bob computes (h_A)^y mod p, both equal to g^xy mod p	MSCS::netfund::netsec::ipsec
What makes Diffie Hellman secure against an eavesdropper?	Knowing p, g, h_A and h_B, it is hard to calculate K	MSCS::netfund::netsec::ipsec
What are the two IPsec authentication options, and where is the choice made?	Shared private key or digital certificate; decided during the SA-1 parameter exchange	MSCS::netfund::netsec::ipsec
What does the SA-2 parameter exchange set up?	The security association for actual traffic exchange, plus traffic selectors that determine what traffic is allowed through the tunnel	MSCS::netfund::netsec::ipsec
What is a traffic selector defined by?	A 5-tuple of IP source/destination, protocol, and transport source/destination	MSCS::netfund::netsec::ipsec
What is the difference between AH and ESP in IPsec?	AH (Authenticating Header) provides integrity only; ESP (Encapsulating Security Payload) provides integrity and confidentiality	MSCS::netfund::netsec::ipsec
What is the difference between IPsec transport mode and tunnel mode?	Transport mode is mostly for a single endpoint; tunnel mode is mostly for a whole site and adds a new IP header	MSCS::netfund::netsec::ipsec

What does RPKI stand for?	Resource Public Key Infrastructure	MSCS::netfund::netsec::rpki

What three prefix states does a router check on receiving a BGP update under RPKI?	Valid, Invalid, and Unknown	MSCS::netfund::netsec::rpki

What three things does the TLS handshake accomplish?	Agreement on parameters, authentication of the server, and setup of a private (session) key	MSCS::netfund::netsec::tls
List the TLS 1.2 handshake messages in order.	Client Hello, Server Hello, Server Certificate, Server Hello Done, Client Key Exchange, Change Cipher Spec, Finished, then Change Cipher Spec and Finished from the server	MSCS::netfund::netsec::tls
What does the Client Hello contain?	What the client supports and prefers, such as ciphers (DES, AES) and data integrity algorithms (SHA1, MD5)	MSCS::netfund::netsec::tls
